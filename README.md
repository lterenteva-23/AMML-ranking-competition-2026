# AMML ranking competition 2026

Задача: ранжировать фрагменты русскоязычной Википедии по релевантности поисковому запросу. Оценка считается по среднему NDCG@10 для запросов.

Код находится в `solution.ipynb`. Через `%%writefile` в ноутбуке создаются модули `src/` и `jina/`, дальше последовательно считаются признаки, обучаются модели и собирается `submission.csv`.

## Что делала

Сначала посчитала текстовые признаки: BM25, TF-IDF, пересечения слов запроса с заголовком и текстом, косинусные сходства эмбеддингов, признаки статьи и группы кандидатов. Отдельно дообучила bge-reranker-v2-m3 и получил его OOF-предсказания.

На этих признаках и zero-shot скорах Qwen3 и BGE обучила LightGBM LambdaRank. Потом попробовала отдельные реранкеры Jina v2 и Jina v3, а также дообучение Jina v3 и Qwen3 через LoRA. В итоговом варианте объединила их оценки.

Для BM25 и TF-IDF используются тексты из train и test без тестовых меток: это нужно для расчёта статистик корпуса. Дообучение моделей и подбор весов проводились по размеченному `train.csv`.

## Итоговый бленд

Перед сложением скоры нормализуются отдельно внутри каждого запроса (z-score). Используются пять компонентов:

```text
pred = z(stack) + 1.0·z(jft2) + 0.5·z(jv3) + 1.0·z(fv3) + 0.25·z(lora)
```

| Компонент | Что используется | Дообучение | NDCG@10 на валидации |
|---|---|---|---|
| `stack` | LightGBM LambdaRank, 5 фолдов × 5 сидов; OOF BGE, BM25, TF-IDF, эмбеддинги, метаданные и zero-shot скоры | да | 0.9535 |
| `jft2` | jina-reranker-v2-base-multilingual, 2 эпохи | да | 0.9607 |
| `jv3` | jina-reranker-v3, zero-shot, два порядка кандидатов | нет | 0.9653 |
| `fv3` | jina-reranker-v3 с LoRA r=16 и обучаемым проектором, 70 минут на фолд | да | 0.9665 |
| `lora` | Qwen3-Reranker-4B с LoRA r=16, фолды 0 и 1 | да | 0.9525 / 0.9505 |

## Проверка качества

Разбила train на 5 фолдов по компонентам связности графа «запрос — документ». Если один документ встречается в нескольких запросах, эти запросы попадают в один фолд. Все OOF-предсказания и обучение стека опираются на одно разбиение.

Веса ансамбля проверяла отдельно: подбирала их на четырёх фолдах и оценивала на оставшемся.

| Вариант | OOF NDCG@10 |
|---|---:|
| stack + jft2 + jzs + jv3 | 0.9732 |
| stack + jft2 + jv3 + fv3, вложенная проверка | 0.9742 |
| stack + jft2 + jv3 + fv3, веса на всех фолдах | 0.9752 |

Для предыдущего бленда `stack + jft2 + jzs + jv3 + lora` Public LB был 0.965994. Значения 0.9742 и 0.9752 относятся к четырёхкомпонентному бленду из таблицы, а формула выше — к итоговому варианту с Qwen3-LoRA.

## Запуск

Зависимости перечислены в `requirements.txt`. Первая ячейка предлагает выбрать три файла: `train.csv`, `test.csv`, `sample_submission.csv`. 

Дальше ячейки выполняются по порядку. Флаги `RUN` включают и выключают отдельные этапы. В конце создаётся `submission.csv` с колонками `id` и `prediction`; последняя ячейка скачивает его.
